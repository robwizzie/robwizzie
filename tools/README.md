# tools

- `build_svgs.py` builds the animated `assets/header.svg`, `assets/pool.svg` and `assets/footer.svg`.
- `cards.py` builds the project preview cards in `assets/projects/`.
- `stickers/` holds the Flamey stickers from the Mile A Day app used in the header.

```bash
python3 tools/build_svgs.py
```
